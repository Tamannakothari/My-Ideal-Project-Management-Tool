# Project Management Tool Proposal

## What are you building? Who is it for?
I am building AuraPM, an all-in-one project management and learning platform. It combines task boards, a calendar, and project-based collaboration tools. It is designed for students, small teams, and anyone managing group work or personal projects.

## Why? What problem does it solve?
Most project management tools are either too complex or too simple. AuraPM solves this by bringing the most useful features together in one clean and aesthetic platform. It helps users stay organized, manage tasks by project, and learn basic project management concepts in one place.

## MVP (Minimum Viable Product)
- Create and switch between projects  
- Add tasks to To Do, In Progress, and Done  
- Basic calendar with month switching  
- Add collaborators (emails) per project  
- Simple project management learning pages  

## Stretch Goals
- Drag and drop tasks into calendar dates  
- Save data using local storage so projects don’t reset  
- More visual dashboards and analytics  
- RACI matrix builder inside the app  
- Better animations and UI improvements (Apple-style design)  

## Technologies Used
- HTML, CSS, JavaScript  
- DOM manipulation for dynamic updates  
- LocalStorage (for saving data in future version)  
- Maybe some APIs (future idea for calendar or collaboration features)  
- No frameworks used (pure frontend for simplicity and control)
