RACI Matrix 📊

A RACI Matrix defines roles and responsibilities in a project.

What RACI Means

R = Responsible (does the work)

A = Accountable (final decision)

C = Consulted (gives input)

I = Informed (kept updated)

How to Use

List tasks → assign R, A, C, I for each person

Template

Task | Person A | Person B | Person C
