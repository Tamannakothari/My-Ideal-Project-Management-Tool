# Final Project: My-Ideal-Project-Management-Tool
 
**All-in-One Project Management & Learning Dashboard**

# Project Description  
This tool is a project management web app that helps users plan tasks, manage projects, and learn project management concepts in one place.  

It is designed for **students, teams, and beginners in project management** who want a simple but powerful tool to organize work and understand key concepts like Agile, Scrum, Stakeholder Management, RACI, Kanban, WBS, and Risk Management in simple terms.

# Live Website 
https://tamannakothari.github.io/My-Ideal-Project-Management-Tool/

# Features  
Users can:

- Create multiple projects  
- Add tasks (To Do, In Progress, Done)  
- Drag and drop tasks between lists  
- Add team members (emails per project)  
- Use a monthly calendar with events  
- Switch between months  
- Learn project management concepts (WBS, Agile, Kanban, RACI, etc.)  
- Navigate between different concept pages  
- Store data per project  


# Technologies Used  
- HTML  
- CSS (pastel UI design)  
- JavaScript (DOM + logic + drag/drop)  
- Local project state management (JS objects)

# Challenges Faced  
- Calendar alignment issues (days not matching dates)  
- Drag-and-drop not working for to-do list
- Data disappearing when switching tabs  
- Tasks not saving per project correctly  
- UI layout shrinking or breaking on updates  

I solved these by fixing JavaScript logic, improving DOM selection, and separating project data properly.
